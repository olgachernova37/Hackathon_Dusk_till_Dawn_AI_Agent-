## 1. OpenAI — найперше ⭐

**Навіщо:** без ключа не працюють три ролі в маркетплейсі: агент-покупець, агенти-виконавці і суддя.

**Що просити:**
- API-ключ із кредитами на ніч
- Яку модель радять для дешевих швидких викликів (зараз у коді `gpt-4o-mini`, змінюється через `OPENAI_MODEL`)

**Що зробити одразу:** вставити ключ як `OPENAI_API_KEY` на сайті (Vercel → Settings → Environment Variables), передеплоїти і прогнати **Run the demo** на `/en/market`.

**Як спитати:**
> "Hi! Could I get an OpenAI API key with credits for the night? And which model do you recommend for many small, cheap calls?"

## 2. Apify — найцікавіше для нас ⭐

**Навіщо:** у маркетплейсі вже є виконавець **Apify Scout**: він запускає актор Apify, шукає в інтернеті і повертає звіт із джерелами. Це перший виконавець, який є справжнім зовнішнім сервісом, а не моделлю на нашому сервері.

**Що просити:**
- **Кредити Apify** (їх обіцяли всім командам) і API-токен → вставити як `APIFY_TOKEN`
- Порада, **який актор найкраще підходить** для пошуку з джерелами. Зараз за замовчуванням `apify/rag-web-browser`, змінюється через `APIFY_RESEARCH_ACTOR`
- Порада, який актор допоможе **перевірити гаманець або профіль виконавця** (хто власник адреси, репутація) — це можна додати до перевірки через The Graph

**Головне питання — x402.** В Apify є оплата через x402 ([документація](https://docs.apify.com/integrations/x402)). Як це працює насправді:
- агент платить **USDC у мережі Base (mainnet, справжні гроші)** і отримує передплачений токен Apify
- мінімум **$1**, токен діє **14 днів**, залишок не повертається
- потрібен гаманець Coinbase Agentic Wallet і підтвердження через email
- працюють **не всі актори**: лише з оплатою pay-per-event без окремої плати за платформу і без Standby. `rag-web-browser` під ці умови **не підходить**

Наш код уже готовий до цього: передплачений x402-токен — це той самий `APIFY_TOKEN`. Тож питання ментору:

> "We have an agent marketplace with escrow. One provider agent runs an Apify Actor. Can we pay for that Actor with x402 tonight? Which Actor that supports x402 would you use for web research with sources?"

*«У нас маркетплейс агентів з ескроу. Один агент-виконавець запускає актор Apify. Чи можемо ми сьогодні оплатити цей актор через x402? Який актор із підтримкою x402 ви б узяли для пошуку з джерелами?»*

⚠️ x402 тут — це **справжні гроші на mainnet**. Робити тільки якщо ментор допоможе і сума мала ($1).

## 4. Masumi — реєстр і ескроу (тільки якщо ментор скаже «встигнете»)

**Навіщо:** замінити наш список виконавців їхнім **реєстром агентів**, а запис ескроу — їхнім **контрактом ескроу**. Тоді зникають дві головні «симульовані» частини з HACKATHON.md.

**Ризик:** Masumi працює на **Cardano**, а наш проєкт — на Ethereum. Новий стек за одну ніч.

*«У нас є пошук виконавця, ескроу і суддя, але ескроу — лише запис у базі. Скільки часу займе використати реєстр і ескроу Masumi? Одна ніч — це реально?»*
